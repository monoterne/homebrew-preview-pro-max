# Preview Pro Max for Homebrew

Install on Apple silicon with macOS 15 or later.

```sh
brew tap monoterne/preview-pro-max
brew install --cask monoterne/preview-pro-max/preview-pro-max
```

Run `brew update` and `brew upgrade --cask preview-pro-max` to update.

[Application and release instructions](https://github.com/monoterne/PreviewProMax)
